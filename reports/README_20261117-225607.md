## 吞吐瓶颈记录

- 单步 512 样本纯 GPU 计算：14.8 ms → 34.6k 样本/s，即 epoch 理论下限 213 s
- 特征构造 `SGFGameDataset.__getitem__`：0.063 ms/样本 → 12 worker 合计约 38 s/epoch，不是瓶颈
- 实测磁盘读仅约 4 MB/s（`vmstat bi` 7–8.8k blocks/s）、swap 占用 2.2 GB、page cache 6.7 GB 装不下 4.12 GB 训练数组 → 随机 memmap 读盘为主要限制
- `train.py` 旧版每步 `float(loss.detach())` 强制 GPU 同步，进一步降低利用率（GPU 利用率在 3%–94% 间跳动）
- 结果：实际 705 s/epoch，约为 GPU 下限的 3.3 倍
